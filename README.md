# 🛒 meu-ecommerce - Auditado e Validado pelo W3C

Projeto prático desenvolvido na Unidade Curricular de **Linguagem de Marcação (HTML5 & CSS3)**.

## 📁 Estrutura de Arquivos do Projeto
O projeto está organizado da seguinte forma:
- `img/` — Diretório contendo as imagens dos produtos e elementos visuais.
- `index.html` — Vitrine principal do e-commerce.
- `produto.html` — Detalhes técnicos e visualização de um produto específico.
- `carrinho.html` — Listagem dos itens selecionados para compra.
- `cadastro.html` — Formuário de identificação e checkout.
- `style.css` — Folha de estilo responsável por todo o design responsivo.
